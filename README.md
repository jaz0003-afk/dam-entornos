# Cierre, nuestro proyecto completo

En el readme, explica como desarrollarias  una pequeña aplicacion o juego 

01. Problema, platarforna y lenguaje 

Una aplicacion web o una pequeña aplicacion de movil donde el usuario introduce una lista de opciones (por ejemplo: Pizza, Sushi, Hamburguesa) y al pulsar un boton, el sistema elige una opcion al azar con una pequeña animacion visual

La plataforma en la que se podria usar la aplicacion seria multiplatadorma es decir se podria usar en todas las plataformas como ordenador, movil, tablet, navegador...

El lenguaje que usaria sera HTML para ver de forma visual la aplicacion mientras la voy creando y le añadiria CSS para darle estilo a la aplicacion 

02. Algoritmo o ejemplo de paradigma que usarias
Una parte de la apliacion en la que se vea el titulo y el lugar donde tienes que escribir pondria algo asi:
<!-- <title>Ruleta Aleatoria</title> -->
<!-- <h1>Escribe para elgir<h1> -->

Para que el boton aparezca usaria algo asi:
<!-- <input type="button" id="button1" value="Elije" onclick="pulsar()"> -->

03. Como llega el codigo a ejecutarse 
Para ejecutar la aplicacion solo hay que poner el enlace en internet y desde ahi la usas o si lo quieres desde ahi lo puedes descargar
